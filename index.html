No conocidos Conocidos
  • <svg> — contenedor que dibuja gráficos vectoriales directamente en el HTML.
  • <path> — dibuja una forma libre dentro del <svg> a partir de coordenadas y curvas (atributo d).
  • <rect> — dibuja un rectángulo definido por posición (x, y) y tamaño (width, height).
  • <line> — dibuja una línea recta entre dos puntos (x1,y1 a x2,y2).
  • :root — selector raíz donde se declaran las variables CSS globales (--color: valor).
  • scroll-behavior: smooth — hace animado el desplazamiento entre secciones.
  • -webkit-font-smoothing — prefijo WebKit que suaviza el renderizado del texto.
  • max-width: var(--max) — límite de ancho usando una variable CSS de :root.
  • :focus-visible — aplica estilo solo cuando el foco viene del teclado (accesibilidad).
  • @keyframes — define los pasos de una animación, usados luego con animation.
