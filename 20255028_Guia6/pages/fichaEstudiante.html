Expresiones regulares en JavaScript

Una expresión regular es un patrón que describe un conjunto de cadenas de texto. En JavaScript son objetos RegExp y se pueden crear de dos formas: con una literal entre barras, /^[0-9]+$/, o con el constructor new RegExp("^[0-9]+$").

El método patron.test(texto) devuelve true si el texto cumple el patrón y false si no. También existen texto.match(), texto.replace() y patron.exec() para buscar, reemplazar o extraer partes del texto.

Elementos más usados:

  • ^ y $: inicio y fin del texto. Obligan a que todo el valor cumpla el patrón, no solo una parte.
  • [A-Z], [0-9]: un carácter dentro del rango. \d equivale a [0-9] y \w a letras, números y guion bajo.
  • {n}, {n,m}, +, *, ?: cuántas veces se repite lo anterior (exactamente n, entre n y m, una o más, cero o más, cero o una).
  • ( ) agrupa, | significa "o" y \1 repite lo que capturó el primer grupo.
  • \ escapa caracteres especiales, por ejemplo \. para un punto literal.
  • Banderas: i ignora mayúsculas y minúsculas, g busca todas las coincidencias.

Campo Expresión regular Qué valida
Carnet /^[A-Z]{2}[0-9]{3}$/i Dos letras y tres números. Ejemplo: AB001
Nombre completo /^[A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+( [A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+)+$/ Al menos dos palabras separadas por un espacio, solo letras (con tildes y ñ)
DUI /^\d{8}-\d$/ Formato ########-#
NIT /^\d{4}-\d{6}-\d{3}-\d$/ Formato ####-######-###-#
Fecha de nacimiento /^(0[1-9]|[12]\d|3[01])([\/-])(0[1-9]|1[0-2])\2(\d{4})$/ Día, mes y año (dd/mm/aaaa o dd-mm-aaaa). Además se comprueba que la fecha exista y no sea futura
Correo electrónico /^[\w.+-]+@[\w-]+(\.[\w-]+)*\.[A-Za-z]{2,}$/ usuario@dominio.ext
Edad /^[0-9]{1,3}$/ Solo números (de 1 a 3 dígitos)
